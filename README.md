# DeskFlow – מערכת לניהול קריאות שירות IT

פרויקט בקורס תכנות מתקדם – שלב 1.

---

## הצעת הפרויקט

**1. שם ותיאור.** DeskFlow – מערכת לניהול קריאות שירות IT. המערכת קולטת תקלות שעובדי הארגון מדווחים עליהן, מתעדפת אותן ומשבצת אותן לטכנאים עד לסגירתן.

**2. הצורך העסקי.** בארגון בינוני קריאות IT מגיעות במייל, בטלפון ובמסדרון. אין תמונה אחת של מה פתוח, תקלות קריטיות נתקעות מאחורי בקשות שוליות, ואין דרך לדעת אם עומדים בזמני התגובה (SLA). המערכת מרכזת את כל הקריאות במקום אחד, מטפלת בהן בסדר הוגן ומקדימה את מה שבאמת דחוף.

**3. משתמשים מרכזיים.**
- **עובד מדווח** – פותח קריאה ועוקב אחרי הסטטוס שלה.
- **טכנאי** – מקבל את הקריאה הבאה בתור, מטפל בה וסוגר אותה.
- **מנהל IT** – רואה עומסים, חריגות SLA וסיכומים לפי קטגוריה.

**4. התהליך העסקי המרכזי.** עובד פותח קריאה ← המערכת מסווגת אותה (חומרה / תוכנה / רשת) וקובעת דחיפות ← קריאה רגילה נכנסת לתור לפי סדר הגעה, וקריאה דחופה נכנסת לתור עדיפויות ← טכנאי פנוי מקבל את הקריאה הבאה (קודם הדחופות) ← הסטטוס עובר ל"בטיפול" ← הטכנאי פותר וסוגר. **התוצאה:** קריאה סגורה עם זמן טיפול מתועד שאפשר לבדוק מול ה-SLA.

**5. זרימת המידע.**
- **נכנס:** פרטי המדווח, תיאור, קטגוריה, דחיפות, מיקום ומועד פתיחה.
- **מעודכן:** טכנאי משובץ, סטטוס, הערות ומועד סגירה.
- **מופק:** הקריאה הבאה לטיפול, קריאות פתוחות לפי טכנאי, חריגות SLA וספירה לפי קטגוריה.

**6. הערך העסקי.** פחות זמן השבתה, כי תקלות קריטיות מטופלות ראשונות. חלוקת עבודה מאוזנת בין טכנאים. אף קריאה לא הולכת לאיבוד, ולמנהל יש נתונים כדי להחליט היכן חסרים משאבים.

**7. ישויות וקשרים.** `Employee` פותח קריאות (אחד לרבים). `Technician` מטפל בקריאות (אחד לרבים). `Ticket` היא ישות הבסיס, וממנה יורשות `HardwareTicket`, `SoftwareTicket` ו-`NetworkTicket`. `Helpdesk` **מכיל** את כל הקריאות והטכנאים.

**8. תרחישי שימוש.**
1. **מתג חדר השרתים נפל:** נפתחת קריאת רשת קריטית. היא נכנסת לתור העדיפויות, והטכנאי הפנוי הבא מקבל אותה לפני בקשות רגילות שהגיעו קודם. *ההחלטה שנתמכת:* מה מטפלים קודם.
2. **בדיקת עומסים בסוף יום:** המנהל רואה אילו קריאות חרגו מה-SLA וכמה קריאות פתוחות יש לכל טכנאי. *ההחלטה שנתמכת:* העברת קריאות בין טכנאים או תגבור משמרת.

**9. הרחבה עתידית.** קישור קריאות חומרה למלאי ציוד, כך שטכנאי יוכל להחליף ציוד תקול ישירות מתוך הקריאה, והמערכת תתריע כשפריט במלאי עומד להיגמר.
